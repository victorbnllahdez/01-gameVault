# Game Vault - Ejercicio 01

API NestJS + TypeORM + PostgreSQL y app React Native (Expo)
que muestra una colección de videojuegos.

## Arranque
- Crear la base de datos `databridge_e01` en PostgreSQL
- Backend: `cd backend && npm install && npm run start:dev`
- Frontend: `cd frontend && npm install && npx expo start`
